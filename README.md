# StructRule

StructRule은 폴더 구조와 이름 규칙을 설계하고, 선택한 프로젝트의 규칙 위반을 확인하는 데스크톱 앱입니다.

## 안내

- [개인정보 처리방침](PRIVACY.md)
- [고객 지원](SUPPORT.md)
- [문제 신고 및 기능 제안](https://github.com/yohns-dev/StructRule-Support/issues)
- [공식 안내 페이지](https://yohns-dev.github.io/StructRule-Support/)

StructRule은 계정 가입을 요구하지 않으며 광고, 분석 도구, 사용자 추적 기능을 사용하지 않습니다. 사용자가 선택한 폴더와 규칙 정보는 기기 안에서 처리됩니다.

이 저장소는 지원 및 정책 문서를 위한 공개 저장소이며 앱 소스 코드는 포함하지 않습니다.

---

StructRule is a desktop app for defining folder structures and rules and checking selected projects for rule violations. This public repository contains support and policy documents only.
